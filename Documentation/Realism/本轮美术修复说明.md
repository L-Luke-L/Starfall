# 星陨边境 · 美术与模型修正版

本轮已在 Unity 6000.3.24f1、Built-in、Direct3D 11 下完成导入、进入 Play 和五个区域的实际画面检查。此次 PNG 为游戏场景中真实模型的 Unity 相机渲染；较早的 Three.js 图册仍是独立预览，不能混同。

## 使用

当前解压工程已经同步本轮修改：先停止 Play，等 Unity 导入与编译结束，再进入游戏。编辑状态的原场景仍保留原外观，新外观在运行时装配。打开 `Assets/Scenes/Scene01_Starfall.unity` 可从原流程开始。

无需因本次美术更新重启电脑。Animation 和 ParticleSystem 内置模块依赖已保留，两个 Packages JSON 已解析校验。完整工程包不包含 Library、Temp 或个人存档。

## 本轮修正

- 天线：重建为双层抛物面反射器、合理管径的桅杆、斜撑、基座、抱箍、馈源支架、线管和设备箱。原有交互、完成状态和指示灯沿用；消除细线桅杆及巨大悬空青色块。
- 模型比例：导入模型先消除原几何体非均匀缩放，再等比装入原尺寸范围。扫描石块不再被强行拉成尖柱；保持原碰撞与导航数据。
- 头颈：根据骨骼实际轴向校正，分配颈部转角、限制转头范围、平滑跟随并消除固定侧歪。保留原飞翼动画、攻击时间和命中逻辑。地龙增加表现用脚底高度修正。
- 古龙：等待角色及区域初始化完成后装配，修复部分区域不出现的时序问题；移除会拉成长线的 24 条后加翼筋，保留原翼骨、翼膜、114 块新增鳞甲及六支头冠。附修正后的 Blender 文件。
- 建筑：舱壁和设施增加几何倒角、板缝、角部加强、通风百叶、基座；窗框按米制尺寸生成，避免非均匀父级造成拉长。残缺屋顶补浅梁和立缝。船坞货箱补门板、密封缝、铰链、锁杆和侧面加强筋。
- 材质：取消生物皮肤的金属反光，降低过强高光；冰霜矿体改为有晶面结构的矿物；核心区域的悬浮玄武岩从方块改为不规则岩石，保留其原有悬浮设定。没有用强泛光、景深或暗画面掩盖模型。
- 清理：删除展示宇航服的运行时摆放，避免角色残片出现在信标旁；避免给已有 LODGroup 的扫描资源重复注册 LOD。

## 验证范围

`art-fix-runtime-checks.txt` 记录 Scene03 至 Scene07 的加载、场景模型、头部转角和区域可达性检查。五个区域可达性检查均通过，测试期间未记录游戏运行时异常。验证以隔离 QA 状态运行，没有载入或改写个人 CampaignV1 存档。

图册中的敌人移动 AI 暂停，以固定机位检查骨骼动画；连续帧在动画及 LateUpdate 之后采集，不能代替完整战斗录像。天线完成色切换也经过实际渲染检查。

Unity 编辑器 SearchDatabase 初始化仍出现一条 `ArgumentOutOfRangeException`，栈位于 `UnityEditor.Search`；它没有阻止本轮导入、Play 或场景检查，记录中单独列为 EDITOR_SEARCH_WARNING，没有将其当成游戏代码已修复。

仍未完成：Windows Player 正式构建、目标硬件帧率基准、所有战斗/死亡/存档分支回归。原来的第一人称枪械、手套和换弹动作没有在本轮重做；恐龙腿部表现仍不是完整足部 IK，古龙基础身体贴图的近景质量仍受原资源限制。改进后的建筑是沿原布局的程序化结构细化，不代表全场景已经达到照片级真实度。

原场景、原玩法脚本、数值、碰撞、导航网格、存档格式及流程保留；新增外观网格不添加碰撞。变更集中在 `Assets/Scripts/Art`、`Assets/Resources/StarfallRealism`，另附仅在编辑器专用参数下启用的截图检查工具。Built-in 管线不变。

复用的模型、扫描材质及星图授权见 `Documentation/Realism/已接入资源与授权.csv`、`ATTRIBUTION.txt`。本轮未购买资源。天线和建筑新增几何为项目内自建，复用 ambientCG 金属材质；只参考 NASA 深空天线的结构关系，没有导入 NASA 模型。

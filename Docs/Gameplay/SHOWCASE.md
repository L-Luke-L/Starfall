# 主线演示与实时 CG

演示模式用于课堂展示、答辩和快速介绍《星陨边境》。在同一套实际场景里自动完成核心玩法和守望者主线，每章完成后进入下一章；不要求操作者熟悉路线，也不接伙伴、建设、中继、遗物或遗迹等支线。场景加载、战斗、暂停和主动跳过过场会影响实际展示时间。

## 使用

也可从开始界面选择 **演示模式 → 主线与界面演示** 或 **直看机甲战**。从首页启动不会写入尚未继续的故事，退出后返回首页。开场新增背包、营地仓库、实际存入与取回、补给分类和任务手账导览；机甲战包含移动换位和低血加速。

在游戏中按 Esc 打开暂停设置，选择 **主线演示**，再选择 **开始自动主线演示**。演示期间有章节标题、当前操作说明和进度提示；Esc 可暂停或继续，界面提供退出演示。结束后停留在展示结果页，可退出并返回开始前的故事。正在锻造、上下井或场景切换时，应先完成当前操作再启动。

在暂停设置中选择 **直看机甲战**，可直接观看守核机甲战斗。该预览使用独立的 `GuardianShowcase` 存档，退出后恢复原故事。

展示由程序自动操作：抓钩确实下放和收回矿物，锻造确实完成三次命中，武器确实射击、消耗弹药和换弹，机甲确实经历节点、装甲与弱点阶段。观众可以集中观看，不需要在演示中手动操作角色。

切换星界、打开货舱、选择锻材、合成弹药与炸弹、读取档案、维修飞船和核查核心时，演示会打开对应的游戏面板。面板会保留一段时间，展示配方、操作反馈和完成状态。按 Esc 可暂停并留在当前步骤。

## 主要展示内容

1. 坠落后的星球与营地，开场电影镜头。
2. 抓钩采矿、裂纹矿物、空间核心与首次跃迁。
3. 遗骸区确认活目标和无遮挡弹道后分组射击，再走到货舱和入口信标。
4. 营地整备及完整三击锻造。
5. 后续矿层与撤离战场、医疗站、军用船坞，依次取得主线档案。
6. 第五层异晶与 D4 真相；修船、制作炸弹，保留两条结局路线的原有条件。
7. 守核机甲登场、供能节点、地面预警、实跑离开炮击区域和弱点反击。
8. 生命维持核查、切断现实耦合、锁定撤离锚点，再安装并启动炸弹。
9. 原有 45 秒倒计时撤离、裂隙崩解过场与实际跑回入口信标。
10. 留下完成污染管道、净水设施和播种三个主线尾声交互，再播放新生镜头并展示结果。

重复采矿与批量锻造进行了演示专用的压缩。3D 任务路线由角色实际行走；批量冶炼仍按原配方扣除原矿，额外的弹药和医疗补给只存在于演示故事中。普通模式的 `CampaignRules`、五层解锁、终端知识、Boss 判定、炸弹安全步骤、倒计时和双结局条件继续使用原有实现。演示展示一条完整守望者主线，不强行把两个互斥结局拼成一次通关。

## 过场动画

新增的是**引擎内实时 CG**：直接拍摄游戏场景，包含多段运镜、宽银幕字幕、光环与碎片效果以及程序生成的配乐。它们不依赖联网、外部视频或额外插件，不是预渲染视频资源。可用空格或 Enter 跳过，Esc 暂停；“镜头反馈 · 减弱”设置会限制动态效果。过场退出时恢复原相机、输入、鼠标、人物与临时物体。暂停设置中的 **剧情演出 · 开启/关闭** 控制正常故事里的过场；演示始终保留其完整演出编排。

## 存档隔离

进入前先保存当前故事，再切换到独立的临时 `CampaignShowcase` 存档与新状态。演示中的自动存档、F5、死亡、检查点和结局都不会写入 `CampaignV1`；退出时恢复原故事对象和原存档目录。演示不是继续旧存档的捷径，演示成就和物资不会带回正常故事。

## 验证

`Tools/TestShowcase.ps1` 默认使用本机 `D:\Unity\6000.3.24f1\Editor\Unity.exe`，也可通过 `-Unity` 指定同版本安装。脚本利用 Unity 自带 Roslyn、运行时和引用程序集，编译全部运行时源码并执行托管规则检查，不要求另装 .NET SDK。

```powershell
.\Tools\TestShowcase.ps1
.\Tools\TestShowcase.ps1 -Build -RunQA
.\Tools\TestShowcase.ps1 -RunQA -LifecycleOnly
```

`-Build` 使用原有 `StarfallBuilder.Build` 构建现有七个场景，不重新生成场景。`-RunQA` 执行 `Builds/Windows/Starfall.exe -showcaseQA`，先验证提前退出、存档隔离和暂停，再按真实时长完整跑一遍。验证使用独立测试故事，不读取正常玩家的 `CampaignV1`。不要与其他 QA 参数混用。

输出为 `QA/Reports/Showcase/showcase-report.txt` 及各章完整游戏画面，包含 HUD、演示界面与过场字幕。运行时请保持测试窗口可见。成功日志标记 `SHOWCASE_QA_PASS`，失败标记 `SHOWCASE_QA_FAIL`。构建与运行日志位于 `QA/Logs/showcase-build.log`、`QA/Logs/showcase-player.log`。

`-LifecycleOnly` 运行快速回归，检查开场演出、采矿读数、合成面板渲染、暂停、地下和第一人称退出恢复，并拍摄裂隙及机甲实时 CG。完整流程另外检查弹药合成前后、各星界终端、飞船维修、炸弹安装和结局等面板的实际画面。快速回归结果保存在 `QA/Reports/ShowcaseLifecycle` 和 `QA/Logs/showcase-lifecycle-player.log`。

演示流程截取包含面板和 HUD 的实际窗口画面。指定机位的美术检查将启用的游戏相机按深度合成到渲染纹理中。

验收覆盖独立 State/Store、重复启动防护、暂停计时、退出恢复、正常存档字节不变、五矿层/五坐标、五区档案、修船、守核机甲、炸弹和三项安全检查、撤离与尾声，以及七分钟内完成的完整未跳过流程。测试还检查遗骸区的实弹命中、机甲炮击结算时玩家在伤害区外且无伤、实际跑到信标后成功撤离。自动生成的生物图鉴或委托计数不属于主动完成支线。

单独复测遗骸区可用 `-showcaseQA -showcaseEncounterOnly`，单独复测机甲战可用 `-showcaseQA -guardianShowcaseOnly`。

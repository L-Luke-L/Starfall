# 第一人称遭遇场景 · 断崖盆地

## 进入与返回

地下抓到隐藏怪物，绞盘完全收回后，人物头顶感叹号闪两次，接着淡出进入第一人称外星地表。原矿井场景保留在内存中，暂停原场景控制与显示。

靠近到达点旁的青色返回信标按 E，或按 Esc 后选择“返回矿井”，淡出回到原矿井位置。库存和已经回收的样本状态保留；这个场景目前不结算战斗或燃料奖励。

同目录“第一人称场景试玩”快捷方式可直接进入新场景体验，不需要先抓矿；它不会赠送矿石。

## 操作

- WASD / 方向键：水平自由移动。
- 鼠标：第一人称自由观察；俯仰角限制为 ±85°。
- Shift：奔跑。
- 空格：跳跃。
- Esc：暂停与释放鼠标。
- F11：切换全屏。
- 切出窗口会暂停移动；继续后重新锁定鼠标。

步行速度 4.6 m/s，奔跑 7.2 m/s，跳跃高度约 1.1 m。人物具有胶囊碰撞、重力、台阶处理和斜坡限制；斜向移动不额外加速。意外掉出地形时回到到达点。

## 场景内容

- 240 × 240 米的独立三维地形，中央陨坑、起伏土壤与外围岩坡。
- 独立玄武岩柱、碎石、倾斜岩峰和发光晶簇。
- 星空与银河天空材质、独立三维行星和环带、低角度恒星光照与远景雾。
- 到达信标和四个预留敌人出生点。
- 岩石与地面使用真实三维碰撞；远端岩壁外设边界，防止走出地图。

现有玄脊地龙和苍翼飞龙：两种独立模型、自主巡游与追踪、近战冲撞/撕咬、远程侧移/五连弹、玩家护甲与信标回收。详见 CREATURES.md。玩家武器、怪物生命/死亡、概率掉落和地表采集已在高难度版本接入，详见 HARD_EXPEDITION.md。

## Unity 中编辑

场景：`Assets/Scenes/Scene02_Encounter.unity`。

地形、岩石、晶簇、行星、环带、信标、玩家和光源均为独立对象；不是整张背景图。材质和网格保存在 `Assets/Art/AlienSurface/`，材质着色器保存在 `Assets/Shaders/Alien*.shader`。

- `FirstPersonExplorer`：第一人称视角、移动、碰撞与暂停菜单。
- `BattleTravel`：监听 `RecoveryEncounter.BattleRequested`，载入场景并保留原矿井；返回时卸载遭遇场景并恢复环境设置。
- `BattleTravel.Request`：当前怪物来源、遭遇编号及预留燃料奖励编号。
- `BattleTravel.Entered`：进入完成通知，便于后续生成敌人。
- `AlienSurfaceLandmarks.futureEnemySpawns`：四个预留出生点。
- 菜单 `Starfall / Create First Person Encounter and Build`：重新生成三维场景、接入矿井并构建。会覆盖自动生成的三维场景，因此手工修改前建议另存副本。

## 验证与备份

`Starfall.exe -battleQA` 使用真实抓钩回收隐藏怪物，检查事件顺序、场景载入、视角、落地、移动、奔跑、跳跃、岩石碰撞、暂停、库存保留及两次往返。重新执行该验证后会生成 `QA/first-person-v9/`；旧截图与逐帧录制已清理。


## v11 天空巨兽

盆地上空新增独立的蚀穹巨兽，翼展约 240 米，支持巡弋、巨翼摆动、头部注视和低频咆哮。巨兽现已支持范围攻击、承受伤害和击败结算。详见 SKY_TITAN.md。

## v12 虫洞入口与分散怪物

首次进入后解锁主场景虫洞，支持靠近 E 交互及界面快捷进入，并跨游戏重启保留解锁。盆地现有两种小怪各 3 只，分散巡游并限制同时追击数量；蚀穹巨兽保持一只。详见 WORMHOLE.md。

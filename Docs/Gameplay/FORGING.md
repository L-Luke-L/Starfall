# 矿石锻造与隐藏遭遇 · v7

## 收获种类

地下仍只显示未知矿物外壳，不提前透露材质或是否隐藏怪物。普通矿物回收后计入“未知矿石”；成功锻造后揭示名称。

| 原矿设定 | 三次成功后的收获 | 外观 | 后续用途设定（未实装） |
| --- | --- | --- | --- |
| 陨铁矿 | 陨铁锭 ×1 | 银灰铸面、少量橙色矿脉 | 船体与承重结构 |
| 赤辉铜矿 | 赤辉铜锭 ×1 | 赤铜金属、金色细脉 | 导线与能源连接 |
| 霜蓝钴矿 | 霜钴锭 ×1 | 深蓝钢面、冰蓝矿脉 | 耐热部件 |
| 星髓矿 | 星髓合金锭 ×1 | 紫银合金、青紫细脉 | 特殊核心组件 |

第三次 QTE 命中并完成落锤后，金属入库一次。画面中央出现对应金属锭、呼吸光晕、放射细光与上浮粒子，显示“获得 / 名称 ×1”。开场约 1.15 秒内不接受重试或退出，随后可再锻一块或返回营地。

QTE 调整为适中偏难：命中区 12% / 10% / 8.5%，基础速度 1.12 / 1.30 / 1.48 轨道每秒，匀速时有效窗口约 107 / 77 / 57 毫秒；三轮限时 2.9 / 2.5 / 2.2 秒。每轮先提供 0.32 秒观察时间，不消耗计时，期间输入忽略。任一轮失误或超时损失当前矿石；失败人物划过，车间渐变虚化。Esc 暂停计时。

## 车间造型

人物改用同一姿势表中的准备、蓄力、落锤三帧，统一大小、脚底和身体比例；按原图比例绘制，不拉伸。铁砧重制为厚重铸铁底座与短砧角，使用左侧暖炉光和冷色环境反光。角色、铁砧、接地阴影、矿石、火花均独立绘制。背景继续使用暗色车间，保持精简文字。

## 隐藏怪物回收

现有 12 个地下样本中的 2 个使用 `DormantEncounter` 配置，矿物外观保持不变。

1. 抓钩接触样本时只回收，不立即触发。
2. 绞盘完全收回，样本离开抓钩后，人物头顶显示感叹号。
3. 感叹号亮 0.24 秒、灭 0.22 秒、再亮 0.24 秒，随后熄灭。
4. 总计约 0.94 秒后调用一次战斗入口通知。

隐藏怪物不进入矿石库存、不显示“矿石+1”，也无法锻造。同一样本不能重复触发。闪烁期间临时阻止移动、抓钩和营地交互。

**v9 已接入第一人称外星地表场景。** 两次感叹号后由 BattleTravel 自动切入断崖盆地，可自由行走、奔跑、跳跃和返回矿井。v10 已加入两种自主移动与攻击的怪物，以及玩家受伤反馈；已加入玩家武器、概率燃料掉落和结算，详见 FIRST_PERSON.md 与 CREATURES.md。

## 后续接入

`SceneDirector.encounter` 指向 `RecoveryEncounter`。

- C# 事件：`BattleRequested`；Inspector 事件：`onBattleRequested`。
- 参数 `EncounterRequest` 携带 `source`、`sourceId`、`encounterId`、`fuelRewardId`、`recoveryPosition`。

## QTE 节奏变化 v8

每块矿石使用三种节奏各一次，顺序随机；连续锻造时第一锤不会重复上一块的开局节奏。轨道旁仅显示两字标签。

- **匀速**：指针固定速度往返，目标位置随机。
- **变速**：指针在基础速度上下 17% 范围平滑变化，不瞬移、不突然跳速。
- **游移**：指针匀速，目标区缓慢左右移动，移动幅度限制在轨道的 5%，上方短线标记移动范围。

每轮方向、目标位置和节奏相位都会变化。所有模式的最短理论命中窗口均比 v7 更宽；暂停同时冻结指针、目标区、准备时间和倒计时。挥锤时锁定本轮轨道，下一轮开始才刷新。

三次成功产出、一次失误损失矿石、四种金属收获以及隐藏怪物入口均保持原规则。验证覆盖所有模式、三轮参数、双向指针、不同目标位置和节奏相位，检查边界、连续性与 60 帧下的多次命中机会。

v8 脚本备份：`RevisionBackups/before-forging-v8.zip`。

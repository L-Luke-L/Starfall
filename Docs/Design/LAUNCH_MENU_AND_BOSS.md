# 开始界面与机甲战更新

## 开始界面

- 没有正常故事存档：开始、演示模式、设置。
- 已有有效故事存档（包括恢复的备份）：重新开始、继续游戏、演示模式、设置。
- 灰色像素金属长条按钮，铆钉、明暗倒角、金属纹理与焦点标记；中央上方为程序绘制的 STARFALL 像素字标，不依赖额外图片或网络。
- 鼠标点击，方向键 / Tab 选择，Enter / 空格确认，Esc 返回子菜单，F11 全屏。16:9、4:3 与超宽屏按安全画幅缩放。
- 设置包含声音、镜头反馈、剧情演出和全屏切换。声音、镜头反馈与剧情设置跨启动保留。
- 首页冻结世界并阻止自动、手动及退出保存。继续游戏后才恢复原矿井 / 星界。重新开始先确认并保留 previous-story 备份；损坏存档在覆盖前单独保留带时间戳的文件。

## 演示扩展

首页可启动完整主线和机甲战两种演示。开始前不会创建玩家进度，退出返回首页；游戏内启动仍恢复原故事并暂停。

开场后依次展示背包、营地仓库、实际存入两份医疗包、实际取回、补给分类和任务手账。使用真实面板及容器事务，弹药与医疗包仅属于演示临时故事；Esc 可暂停阅读。

## 守核机甲

在原核心战场范围内横移并跟随玩家纵向调整，常态 1.45 米/秒，生命低于一半后 2.15 米/秒。步行时双腿交替抬升。保持与玩家的距离并检测阻挡，不驶出核心场地。

蓄力时停稳，预警区域锁定后不会追着玩家移动；核心暴露时停稳，保留射击与镐击窗口。暂停、过场、玩家在安全区或倒地时不移动，死亡后停机。自动演示每帧更新目标位置。

```powershell

.\Builds\Windows\Starfall.exe -launchQA
.\Builds\Windows\Starfall.exe -showcaseQA -guardianShowcaseOnly
.\Builds\Windows\Starfall.exe -showcaseQA
py -3 Tools/CheckUnityAssetReferences.py
```

首页验证使用每次独立的 LaunchVerification 子目录，报告与多比例截图位于 QA/Reports/Launch。机甲验证检查实际位移、暂停冻结、实弹击杀、无伤躲避、死亡停止及故事恢复。完整演示覆盖全部主线。

本轮同时修复高帧率下 CharacterController 的 0.001 最小移动阈值吞掉小步位移、导致自动行走卡住的问题。演示 QA 显式使用 60 FPS 并预热交换链，避免隐藏窗口忽略垂直同步及首帧截图为空。

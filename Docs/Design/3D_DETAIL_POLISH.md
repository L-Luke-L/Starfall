# 3D 场景细节改善

本版保持原有玩法、任务流程、操作、数值、存档、碰撞和导航数据。

- AlienGround 材质：在原有配色上添加细微表面法线、尘土与裸岩粗糙度差异。覆盖盆地和五个探索区；不修改 2D 地表、地下、锻造画面。
- SurfaceDetailPolish：进入 3D 区域后自动补充小型贴地玄武岩碎石。避开出生区、返回信标周围与中央盆地；采用独立固定随机种子，不干扰玩法随机数。仅一个合并网格，无碰撞、交互或导航组件；离开场景时释放生成网格。
- 现有投影方向光使用柔和阴影，减少表面阴影偏移。
- 编辑器菜单 Starfall / Polish 3D Scene Details 可将装饰保存到六个 3D 场景，并输出 QA/detail-polish 截图和数量报告。重复执行会替换旧装饰，运行时检测已保存装饰并跳过生成。

## 使用

使用 Unity 6000.3.24f1 打开工程，进入 Assets/Scenes/Scene01_Starfall.unity 后 Play，按原有流程进入探索区即可看到改善。无需运行重建剧情工具。可以直接用原有 Starfall / Build Windows 构建。

## 追加：模拟走路的镜头晃动

第一人称镜头增加随实际移动距离变化的上下起伏与轻微左右摆动，奔跑幅度为步行的 1.35 倍。停下、跳跃、闪避、顶住墙壁时平滑归位；暂停冻结，复活清除残留偏移。沿用暂停菜单的“镜头反馈 · 减弱”开关，可关闭走路晃动。镜头旋转与鼠标瞄准逻辑保持原样。Inspector 可调 Walking camera motion 的三项参数。

本次进行了源码逻辑检查与 ZIP 完整性检查，未完成 Unity 编译或实际试玩。

## 追加：跳跃惯性与真实感渲染

- 起跳与走下平台后保持世界空间水平速度；空中 WASD、鼠标转向和 Shift 不改变水平速度。落地恢复地面控制。原地起跳不能在空中加速；碰撞仍由 CharacterController 处理，撞墙可消耗水平动量。复活/ResetMotion 清除动量。
- 地面坡度影响尘土覆盖；岩壁增加细微层理缝隙；远景颗粒根据像素覆盖淡出以减少闪烁。为无 UV 切线的程序岩石补充着色切线基底。
- 六个 3D 区域的世界相机增加轻微高光压缩、饱和度调整和边缘压暗；UI 相机与 2D 场景不应用该效果。Shader 保存在 Resources 以保留构建引用。
- Ultra 质量档启用 4x MSAA；HDR 和图像后处理下的最终抗锯齿表现需按实际平台确认。
- BattleVerification 的 -battleQA 增加移动起跳后转向/反向输入，以及原地起跳后空中输入的检查。

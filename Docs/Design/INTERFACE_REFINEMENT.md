# 前哨终端界面与缺陷核查

2026-10-24。

## 画风与素材

背包、仓库、手账和长期委托统一为前哨站的工业终端：煤灰蓝金属面板、暖灰文字、铜金标题与选中标记、克制的青色状态提示。用细边框、层次、留白和信息分组表现设备感。

沿用 Kenney 的 UI Pack — Sci-Fi、Game Icons 和 Board Game Icons 共 22 张 CC0 素材，与项目原有矿物美术共同使用。官方来源和原始许可保留在 `Assets/Resources/UI/KenneySciFi/SOURCES.md` 及同目录许可文本中。导入工具对已有贴图也修正为 Texture2D，并保留 Unity GUID。

## 物资整备

- 背包与仓库采用对照格位，详情区显示用途、物品类别、当前堆叠与所在容器总量。
- 提供全部、原矿/异晶、精炼、补给、组件/战术五类筛选；筛选使用实际堆叠索引，分页随类别变化。
- 营地支持 Shift+单击快速存取、当前组转移、一半转移、同类归仓、拆分与整理。容量不足时只转移可接收的数量，剩余物资保留原处。
- 仓库操作仅在营地可用；容量、满仓、急救剂可用状态和操作结果直接显示。消耗最后一份物品后清除失效选择。

## 手账与任务

分类、条目、详情采用三级阅读结构。任务与委托分别显示当前目标、进度、追踪和完成状态；委托奖励与领取条件置于独立卡片。调查条目列表和长文各自滚动，记录时间兼容旧存档的缺失时间字段。

## 本轮修复范围

- 死亡或传送后的运动复位会清除未完成的冲刺。
- 无来源怪物的弹丸仍能与玩家和地形碰撞；已结算弹丸不会在延迟销毁期间重复命中。
- 初始重叠命中使用实际接触点，避免特效跳到世界原点；临时视觉物体的碰撞体立即禁用。
- 读取存档时校验手账、维修记录、锻造预留和嵌套世界记录，损坏时沿用备份恢复并保留原件。有效的旧版、区域 0 和未知内容标识保持兼容。
- 战斗验证清除自动瞬移造成的残留速度，记录真实弹丸命中与预测瞄点，区分测试布置与实际弹道问题。

验证命令、报告和界面截图位于 `QA/README.md`。这些自动化检查覆盖已列出的流程与场景，不能替代完整的人工作战与美术验收。

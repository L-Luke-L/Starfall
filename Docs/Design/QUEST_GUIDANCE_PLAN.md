**星界探索任务指引计划案**

日期：2026-10-25。状态：已获批准并实施；自动检查与交付结果见 [实施与验证说明](D:/Starfall/Docs/Design/QUEST_GUIDANCE_DELIVERY.md)，真人新玩家验收仍待开展。

用户已明确的目标：让完全不了解玩法的玩家，也能依靠游戏内指引完成任务。以下交互方式、接入顺序和验收指标为本方案建议。

**1. 先解决玩家在每一步遇到的问题**

每个任务步骤都应回答：现在要做什么、去哪里、如何操作、为什么暂时不能做、成功后接着做什么。玩家无需先看外部攻略，也无需记住几分钟前的一条通知。

当前源码已提供基础提示：

| 已有能力 | 当前局限 | 改进方向 |
| --- | --- | --- |
| `CampaignView.Objective` 显示一行目标 | 中后期常归纳为“收集修船材料”，缺少具体操作链；主线文字以顺序条件判断 | 按玩家当前任务路线解析实际下一步，分别支持修船和核心调查 |
| 手账追踪伙伴、中继、遗物、勘测、遗迹和委托 | 大部分只有任务名、区域或总数量；建设与主线缺少同等追踪能力 | 统一成可追踪的分步任务，展示前置条件和下一步 |
| 靠近设备显示 E 交互 | 找到设备前缺少持续定位；门锁、电源、伙伴条件常在尝试后才提示 | 远处显示方向，到达后显示操作或具体阻碍 |
| 拾光解锁 Q 扫描 | 当前标记附近物体的有效距离为 25 米、显示约 4 秒，标记形状相同；取得拾光前无法使用 | 基础任务导航从开局可用，扫描继续帮助发现附近物体和次要探索点 |
| 中继倒计时、勘测进度、完成通知 | 尚未与完整任务步骤统一展示 | 将当前挑战状态、剩余目标和失败恢复接入指引 |

上述现状记录取自方案制定时的源码阅读；实施后的运行验证单独记录在交付说明中。

**2. 方案选择与默认行为**

| 方案 | 收益 | 成本与局限 |
| --- | --- | --- |
| 只补任务文案 | 成本较低，较快改善任务说明 | 玩家仍可能找不到目标、坡道或跨区域入口，难以满足零基础目标 |
| 分步任务 + 方向导航 + 到达操作提示（推荐） | 同时解决流程、寻路、操作和前置条件问题，可复用现有手账与场景交互点 | 需要统一任务状态及场景目标注册，并逐类接入 |
| 完整地图 + 全任务路线系统 | 提供更强的全局空间信息 | 地图制作、楼层表达和维护成本较高；仍需补齐分步任务逻辑 |

推荐第二项。默认启用“详细指引”，基础提示不依赖伙伴、装备或新手自行打开手账。暂停页提供“详细 / 简洁 / 关闭”选项，玩家可随时恢复；设置作为设备偏好保存。

开局直接追踪主线。新发现的可选任务显示一条简短说明，并收入手账；玩家主动选择后替换当前追踪。不会因为路过采集物不断切换任务。

跃迁校准后，默认主线为“修复飞船”。取得首份区域档案 J03 后，手账提供“继续修船”和“追查异常”两个可追踪方向；选择只影响当前指引，不锁定结局。追查异常按已获得线索引向下一份区域档案，缺坐标时接回开矿取坐标；取得 J07 后再展开核心隔离步骤。两条路线独立解析，核心路线不受修船完成数量限制。

首次进入一个区域时，将该区域可进行的伙伴求援、勘测、中继和遗迹等目标自动收入任务列表，并给出一次“本区域有可选任务，J 查看”的提示。遗物收集从首区开放；追踪后可导航当前可访问区域内的未收集物，名称和故事在拾取后揭示。未开放区域先显示获取坐标的办法，避免玩家必须偶然碰到设备才知道任务存在。

一次只展开一个任务。临时优先级为：核心撤离 > 已开始的中继挑战 > 玩家选择的任务 > 默认主线。临时挑战结束后恢复原追踪；普通战斗不会自行替玩家改选任务。

**3. 玩家实际看到的指引**

任务区保留在现有目标文字附近，通常使用三至四行，分别显示任务名、当前步骤、目标位置或操作、进度或前置条件。复杂说明放进 J 手账。

例如，追踪“岚 · 战场营救”时：

```text
岚 · 战场营救                         1/2
解除锁住避难舱的绞盘
绞盘  ↗  约 38 米
靠近后按 E 解除；随后前往避难舱
```

距离仅为展示示例。运行时以真实目标位置计算，明确区分直线距离与导航距离。

解除绞盘后，立即改为“前往避难舱 → 靠近后按 E 开启”。岚获救后，显示“岚已返回营地，工坊与霰射器已解锁”，并提供营地使用入口的说明。若玩家已经解除绞盘，追踪时直接从开舱开始。

三种空间情况下分别处理：

- **同区域：**目标在屏内时显示名称与距离，屏外时显示边缘方向箭头。通过墙体遮挡时保留方向指示，抵达有效位置后才显示可操作提示。
- **有楼层或绕行：**船坞甲板优先指向可用坡道入口，再指向上层遗物；隔墙目标必要时引导到通道入口，避免箭头持续把玩家引向墙面。
- **不同区域：**当前阶段指向返回信标、营地虫洞或矿井入口；到达后明确指出应选择的区域或矿层，再继续解析下一步。尚无坐标时先说明怎样取得该区域坐标。

“已经靠近”与“可以交互”分别判断。实际距离、视线、楼层、暂停和前置条件与原交互规则一致。附近有多个设备时，任务目标提示应与本次 E 实际触发对象保持一致。

首次进入地表、地下和第一人称场景时，给出当前步骤真正需要的操作提示：地表 A/D 与 E、地下空格下钩、第一人称 WASD 与 E。首次战斗或生命不足时，补充射击、换弹、近战及手动使用急救剂的方法；已有操作提示可在手账重看。

**4. 按任务类型确定步骤，避免只有一个通用箭头**

| 覆盖内容 | 指引如何推进 | 特殊要求 |
| --- | --- | --- |
| 五层矿井、坐标、遗骸货舱、跃迁校准 | 下井 → 回收矿物 → 触碰核心 → 调查货舱 → 返回信标校准；矿层采完后明确提示启动钻机 | 保留主动交互；首区说明可以绕开怪物取得货舱资料 |
| 修船与逃离结局 | 选择维修项 → 查看缺料及来源 → 采集/锻造 → 回船安装 → 校准导航 → 装填燃料 → 确认起飞 | 材料按真实配方和库存显示；调查核心、支线和 Boss 不列为逃离前置 |
| 核心调查与守望者结局 | 取得所需档案 → 制作炸弹 → 进入核心 → 击破供能节点、攻击开放弱点 → 完成终端隔离项 → 安装 → 确认引爆 → 撤离 → 地表生态任务 | 按实际知识条件逐步揭示；撤离期间突出信标和剩余时间；不代替玩家作权限或结局选择 |
| 六条伙伴支线 | 天线 0/3、异常信号 0/3、绞盘→避难舱、电源→隔离门、岚→吊机、苏禾→三份样本 | 显示尚缺的具体步骤与所在区域，已完成目标退出导航候选 |
| 三处中继挑战 | 先说明规则 → 接通第一座 → 显示未接通的两座和剩余时间 → 完成或重试 | 路线保持稳定，超时说明可以重试且无材料惩罚；暂停行为沿用原规则 |
| 五件遗物与归航星图 | 按当前可访问区域指向未收集遗物 → 收齐后返回营地 → 打开手账复原星图 | 最后一件拾取后仍保留“回营复原”的步骤，直到星图真正完成 |
| 五区勘测 | 找到勘测站 → 靠近 → 长按 E 三秒 → 记录完成 | 显示按住进度，并解释松键、移动或受伤导致的中断 |
| 三处遗迹 | 先引导看现场线索，再操作方向盘、重放结晶序列或调整配平 | 详细模式默认解释规则；主动点击“查看详细提示”后逐级给出具体操作，最终可获得下一步正确操作，保证零基础玩家能完成 |
| 六项长期委托 | 目标、当前数量、可执行的获得方式 → 达标后回营 → 领取 | 区分“目标达成”和“奖励已领取”，达标后不继续要求同类行为 |
| 四项营地建设、制作与模块使用 | 具体解锁条件 → 需要的伙伴任务 → 材料及来源 → 回营建设/制作 → 使用方法 | 不用笼统的“等待解锁”替代条件；制作后说明去哪里装备或怎样使用 |
| 可选精英、变体、回收箱 | 标明可选或回收用途；相关任务需要时定位目标，提供已遭遇的攻击与躲避说明 | 不要求玩家为主线清空全部怪物；死亡回收说明原地取回与营地转运两种办法 |

任务可显示“尚未开启、可进行、缺少前置、进行中、待领取、已完成”。缺少前置时保留玩家原任务，并把当前步骤展开为前置任务的可执行步骤；前置完成后自动接回。目标条件已达成的委托直接进入待领取；不需要领取的任务直接完成。

**5. 手账负责完整说明，现场提示负责执行**

沿用 J 手账，将“当前目标”页扩展为任务入口，提供主线、伙伴、探索、建设和委托分类；现有档案、事实、图鉴与详细玩法页继续保留。

每条任务显示当前步骤、已完成步骤、真实前置条件、目标区域、奖励、追踪/取消追踪、查看操作说明。尚未调查的剧情不展示真相和结局细节；已开放任务应说明下一项能采取的行动。

材料条目显示“需要 / 背包 / 仓库 / 仍缺”。死亡箱与远方掉落单列为“可回收”，不算入立即可用于制作的库存。原矿和成品金属分别列出，并可继续追踪采矿、回营锻造和维修；缺料来源受已解锁矿层、已采空矿点和当前可用应急回收条件约束。

玩家一段时间未推进、重复尝试锁住的交互，或勘测连续中断时，出现一次简短补充提示，并指向手账中的详细帮助。默认等待时长建议 60 秒，仅在可操作的探索时间内累计；暂停、读手账和战斗期间不计入。首次提示后冷却，不反复播报同一句话。

**6. 技术接入以现有任务事实为依据**

建议增加轻量的指引解析模块，统一生成任务的当前步骤、进度、前置原因、提示文案和目标引用。现有剧情、知识、建造、委托与机关状态继续负责实际完成判定；指引不保存第二套任务完成记录，也不负责发奖。

| 接入位置 | 计划改动 |
| --- | --- |
| `CampaignView.cs` | 主目标显示接入统一解析结果；扩展手账任务页；显示缺料、未满足条件和任务完成反馈 |
| `CampaignVoyages.cs`、`CampaignFrontierView.cs` | 将现有追踪键映射到分步任务；统一待领取和完成后的回退 |
| `CampaignRegion.cs` 及区域扩展 | 在交互点创建时注册“区域编号 + 稳定目标键”的语义目标；返回信标、坡道入口、Boss 节点和营地设施补充相应目标 |
| 新增指引解析与显示模块 | 解析前置链、选择当前可执行步骤、投影标记、解析跨区域入口和必要的导航路径 |
| `CampaignRuntime.cs`、`CampaignData.cs`、`CampaignStore.cs` | 复用现有事实与 `trackedObjective`；仅在需要保存已发现任务、已看操作提示时追加有默认值的字段与校验 |
| 原有验证套件及新增指引专项套件 | 覆盖任务解析、实际交互、跨场景、暂停、读档、UI 与原有流程回归 |

现有 `quest:*`、`relay:*`、`relics`、`surveys`、`ruins`、`commission:*` 追踪键保留兼容。任务目标引用场景内实际生成后的 Transform 或位置，尤其注意勘测点会调整落点；不复制一套固定坐标，不依赖可更名的 GameObject 名称。

步骤更新应由任务相关事实、库存变化、场景切换或低频检查触发。更新指引本身不调用会立即保存的 `Changed()`。只在玩家更换追踪或新增长期信息时按现有保存策略持久化，避免标记移动或距离变化引起频繁写盘。

空间指引复用 NavMesh，只有目标或路径显著变化时重算。目标沿用稳定选择，避免多个等价目标间跳动；不把几何最短路径标为“安全路线”。目标离场、销毁、拾取或完成时及时注销。运行时找不到目标则保留任务并提示具体阻碍，不把默认零坐标显示为目标。

不增加自动寻路行走、自动交互或自动确认结局。地图重做、资源数值调整和怪物强度调整不在本次指引范围内。

**7. 分四个里程碑交付**

| 里程碑 | 交付范围 | 进入下一阶段的条件 |
| --- | --- | --- |
| M1：任务步骤与手账 | 统一任务解析；主线分支；前置解释；委托待领取；当前目标任务页；基础操作提示 | 所有任务族都有从当前存档恢复正确下一步的规则与示例，任务说明可独立审阅 |
| M2：首批区域完整指引 | 同区域标记、屏外箭头、距离、跨区域入口；贯通开局→遗骸→校准，以及战场绞盘→避难舱 | 首次接触项目的试玩者能按提示完成两条流程，发现的关键卡点解决后再扩展 |
| M3：五区与全部任务接入 | 接入其余伙伴、样本、吊机、中继、遗物、勘测、遗迹、营地建设、委托、修船与核心结局；处理坡道与撤离 | 覆盖表每项都具备可执行步骤、位置、操作、完成反馈与失败恢复 |
| M4：兼容与可用性验收 | 新旧存档、死亡/满包、重进场景、暂停、分辨率、提示频率与性能回归 | 专项与原有回归检查完成；独立人工试玩通过；遗留项明确记录 |

每个里程碑单独可审阅，M2 形成首批可玩的完整体验。M1 或 M2 尚不能宣称全部任务已覆盖。工期应在 M2 完成后，结合实际地图绕行与 UI 接入工作量估算。

**8. 验收围绕“新玩家能完成”**

自动与运行时验证至少包括：

- 相同存档事实产生一致的当前步骤；乱序完成、跳过已完成步骤、前置切换与双主线都正确。
- 委托数量达标后指向领取；遗物收齐后指向星图；完成步骤后不再导航至已失效目标。
- 未获得扫描时基础指引可用；不同区域先指向入口；无坐标时先指向坐标获取步骤；船坞上层任务经过实际可走的坡道。
- E 提示与真实交互对象、交互距离和视线一致；跨楼层、隔墙、暂停、死亡、读档及目标销毁后不显示错误操作。
- 中继失败可重试，撤离失败恢复原检查点，完成与领取不会多发奖励。
- 旧版一号/二号存档、旧追踪键、缺省新字段、已完成结局和无效追踪键都能恢复合理指引；无效键回退主线并保留原有游戏进度。
- 分别运行 `-campaignQA`、`-lostRealmQA`、`-frontierQA`，再运行指引专项检查；原功能套件通过不等同于指引体验通过。

人工验收建议至少邀请 3 名未参与开发、未读外部攻略的玩家，关闭开发者提示：

- 每人完成开局取坐标、遗骸货舱与校准，以及战场营救，过程中无需口头解释操作或路线。
- 后期使用合法准备的独立存档，交叉覆盖跨区域采样、一次中继、三类遗迹、委托领取、上层遗物、修船起飞及核心撤离；记录准备方式，不能据此宣称完整从零通关。
- 在安全探索阶段，玩家能说出当前任务、下一步操作和目的地；因指引缺失连续 60 秒无法决定下一步，或走到目标前仍无法理解操作，记为待修复问题。
- 检查 1280×720、1600×900、1920×1080 下任务文字、标记、倒计时、准星、生命和弹药区的遮挡；仅靠颜色不能承担唯一的信息区分。
- 有试玩者完成从开局到任一结局的连续流程，并覆盖另一结局关键阶段。无口头指点、无查外部攻略，才满足零基础玩家任务指引的最终目标。
